# CC 独立定根因:判别器塌缩=训练病态(非类不均),gate 不过 → 判别器不接线

> 出自 cc(arbiter)。全量 LOVO 跑完,wb 诚实报"判别器恒输出~1.0、gate 从不触发、误绿持平 2.19%"。cc 独立实测复现并**定根因**——过程中推翻了自己的初始假设(类不均),依证据落到"训练病态"。

## 0. 独立复现塌缩(非采信 wb)
- 缓存 rows(seed0/全11视频)**best_conf 全 399 帧=1.0000,无一<0.3**(含 99 无灯帧)→ gate 永不触发,弃权率 0%,选择退化成 base,误绿=base 的 2.19%,5 seed 全同(std=0)。全部对上 wb 报告。
- 原始 logits(温度前 `forward_logits`,留出08折模型):正 governing mean **+34.82**、负 无灯候选 **+48.97**(负比正还高);sigmoid(>15)=1.0000。**塌缩发生在温度之前** → 温度缩放救不了,cc 早前抓的温度缓存 bug **不是本因**。
- **对任意输入都吐巨正**:纯黑 crop logit **+13.40**、随机噪声 crop **+68.85**(比真灯还高)→ 模型学成**近似常数正函数,对内容无有意义依赖**。

## 1. ⚠️ 撤回初始假设:不是类不均、不是"负样本太少"
- 我先验假设"无灯帧没灯→候选稀→717正 vs 极少负→BCE压全正"。**实测否掉**:全 99 无灯帧候选池 = **1659 个负样本 > 717 正(负:正=2.3:1)**;留出03折训练仍有 ~964 负。
- **有近千负样本、负多于正,却塌成全正、还给噪声打最高分** → 这是**训练/优化/数据病态**,不是样本量或不均。按"测量打架就找bug"([[measurements-disagree-find-the-bug]]),我不把错根因甩给 wb。

## 2. 给 wb 的精确回炉方向(先 debug 训练,别加数据/别调阈值)
1. **仪表化训练**:对单折打印**逐 epoch train/val BCE 曲线** + 训练集上正/负各自的 mean logit。692正+964负若健康应能分开;若 loss 不降 / 负样本 logit 居高 → 优化/代码 bug(而非任务难)。
2. **数值稳定**:现用 `BCELoss(sigmoid)` + logits 飙到 +49/+68(无界增长)。换 **`BCEWithLogitsLoss`(喂 logits)** 标准稳定路径;查是否缺 logit/权重正则、epoch 过多(60)、lr 过大致爆。
3. **过拟合 sanity(最快定位)**:拿 **10 正 + 10 负 单 batch** 让模型 overfit——**连这都分不开 = 铁定代码/数据 bug**(标签错位 / crop 归一化坏 / 正负 tensor 实际没差异)。噪声得分 > 真灯已强烈指向此类 bug。
4. **数据对拍**:抽几张正(governing)与负(无灯候选)crop **存 PNG 肉眼看**,确认裁的是不同东西、非全黑/错框;确认 `tf` 归一化没把内容抹平。
5. 训练确认健康(能分正负)后,**再**回到温度校准 + τ/gate;顺带修 cc 早前的**温度缓存持久化 bug**(reload 退回 T=1.0,续跑不一致,见 `2026-07-31-cc-catch-temperature-cache-bug.md`,仍要修但非本因)。

## 3. wb 已自查的报告口径 bug(认可)
- τ 敏感性表用 `all_pool`(5 seed 拼接 1995 行)→ 漏绿=400;主标尺单 seed 口径漏绿=80。**同口径才可比**,wb 改单 seed 一致,正确。这类拼接口径不一致易误导裁定,改对了。

## 4. 裁定
- **判别器方法本轮 gate 不过**(核心目标"拒无灯干扰"完全没实现,零增益)。按红线**净回退**:`select_gtfree` 生产路径不接判别器,**base 路径(扣05 误绿 2.19%)维持**,权重不入库不接线。
- **不是宣告判别器路线死**:先按 §2 debug 训练(模型给噪声打最高分=明显 bug,不是"任务不可学")。修好能分正负再评估;若训练健康后仍无增益,才谈路线取舍(几何/时序强化 or 换法)。
- 红线不变:gate 不过不接线、GT 不进推理、LOVO 去循环、多 seed 报 worst、权重不进库、先诊断后修。

**一句话给 wb**:塌缩我独立复现(best_conf 全 1.0、噪声 logit +68>真灯 +35=常数正函数)。**但根因不是类不均**——负样本实为 1659>717 正,我推翻了自己的假设。是**训练病态**:先仪表化单折 loss 曲线 + 换 `BCEWithLogitsLoss` + 10正10负单batch过拟合测试定位(连这都分不开=代码/数据bug),别急着加数据或调 τ。本轮判别器 gate 不过、净回退(base 2.19% 维持),修好训练能分正负再评估。
