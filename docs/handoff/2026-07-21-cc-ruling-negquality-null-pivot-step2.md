## 1. 独立复现 + "seed 0 相同"疑点排查(我为什么先查再判)

- 我起初怀疑 wb 报告里"seed 0 与 Step0 三格全同"是错模型/复用 .pt(数据完整性隐患)。**查实:不是。** 日志确认 55 行已装载;两版权重确实不同(关4_11 与 walk→off 都变了),只是 01/10/07 的 argmax 计数没被翻动 → 那三格恰好相同。**符合"粗粒度比率对小权重扰动不敏感"**,非造假、非 bug。
- **但方向是坏的**:补充训练负例让**未见 val 视频 11 的拒识变差**(0.423→0.365)。窄版不仅无用,还轻微有害。

## 2. 为什么窄版必然弱(结构性,不只是"55 太少")
- 55 crop 全来自**单一训练视频 10**,且 `mine_negatives.py` 用 `sample_step=1` 逐帧存 → **大量连续近重复帧**,有效信息量远低于 55。
- **关1/关4 的真考点是泛化到 val 负例 01/11**(从不参与训练)。往训练里加更多**训练负例**无法直接教会模型拒识 01/11 的假绿 —— 只能靠泛化。故训练负例挖矿对 val 负例门**结构性受限**,选项 A(挖全部训练视频)也吃这个亏。

## 3. 裁定:pivot 到 Step2,负例杠杆改宽版留作 fallback
- **采信 wb 选项 C**:下一步 **Step2 信号过滤(正样本提纯,几何保持 cc(B))**。理由:
  1. 直治 关2(07 recall 0.45)/关3(04=0)—— 正样本问题。
  2. **负例门失败的主因很可能是脏正样本**(39% 无信号/median 1.6% → 模型学成"泛绿即 walk",决策边界松 → 对新假绿乱 fire)。清正样本 → 边界收紧 → **间接**改善 off 拒识。这是 wb 的论点,证据(窄负例无效)与之相容,我采信。
- **关键强制实验**:Step2 出版后**必须回测 关1/关4 是否随之上移**。这是验证"脏正样本驱动负例门"假说的判决性测点;若正样本清了而 关1/关4 仍平,再上负例硬杠杆。
- **负例杠杆 = fallback,不废但改造**:
  - **禁止**再跑窄版(单视频/逐帧近重复)。
  - 若 Step2 后负例门仍不过,上 **选项 B 硬负例挖掘**(全训练集跑 classify,选"高置信 walk/stand 但 GT=off"的样本),且**去重/采样保多样**(勿连续帧)。这是比选项 A 更靠谱的负例杠杆。
