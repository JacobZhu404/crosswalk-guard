## 2. 四条硬修订(并入 plan 后再写 §3.2)

### R1. 判别器目标重定义:「有效行人灯 vs 干扰」,不是「governing vs 非governing」
- **理由**:governing性(哪盏管**这条**斑马线)是方向/几何属性,**64×64 crop 里看不见**。计划的负样本A(同帧非governing候选)会混入**未标注的真·非governing行人灯**——尤其多gov视频(02=36、07=43、09=44 多gov帧仍可能有平行斑马线的正脸行人灯没标governing)。把这些正脸真灯打负 = 给判别器灌**不可学的标签噪声**。
- **改法**:判别器学「这是不是一盏真·处于信号态的**行人灯**」(拒反射/信号灯背面/车灯/绿树叶)。正=717 governing crop(都是有效行人灯);**governing 选择(多盏有效灯里挑管这条道的)仍交 L1几何+L2时序**,不压给判别器。弃权门触发 = top候选连「有效行人灯」都不是 → 正中 5/8 无灯干扰;2/8 排序错(选中的背面/反射)也会被判别器压低 → 真灯排上来。目标与两类失败都对得上,且避开标签噪声。
- **负样本口径**:主力=**无灯帧候选(负B,保证是干扰)**;负A(同帧非gov候选)因含真灯风险 → **做 A 消融(带A vs 不带A 各跑LOVO),若 A 拖低泛化就丢**,别默认全用。Jacob 明确点过「信号灯背面」是干扰:背对相机的灯显示背面(暗/红X背),视觉可分,本就该判负;真正噪声只是**正脸的平行斑马线灯**,有界,消融即可裁。

### R2. 无灯数据集中度会毁 LOVO 03 折 + 06/11 弃权率无定义
- 留出03训练时**丢掉 61/99=62% 的无灯负样本**,却要在「75%是无灯」的03上评弃权——**最难折 + 最缺训练信号**,且5/8失败里3个在03。→ **03折单列报告、承认数据不均**,别混进 mean 掩盖。
- **06/11 零无灯帧 → 这两视频「正确弃权率」无定义**。评分台该指标在06/11 显式标 **N/A**,禁用0或100充数拉平均。
- 这正是 **R1 重要的原因**:弃权若靠「是不是有效行人灯」的正向判定(无灯帧top候选压根不是有效灯),就**不依赖 per-video 无灯负样本的充足性**,03折/06/11 才有救。若仍走「governing vs 非」纯相对,03折必崩。

### R3. τ 必须单一全局,选取绝不碰留出测试视频
- 计划§2.1「τ 在 LOVO 折上选」措辞有**去循环风险**:若「折」=留出的测试视频V,则在测试集上调τ = 破坏去循环。
- **要求**:τ 用**训练折内数据(或 inner-CV)**定一个**全局值**,统一施于所有测试折;温度缩放的校准集同样须**排除测试视频**。报告给 τ 敏感性曲线,证明不是碰运气挑的点。**禁止 per-video τ**(等于 per-video 硬编码,红线)。

### R4. 漏绿头寸极窄(基线80/154≈52%),弃权门只会加剧 → 设为硬约束
- 弃权 τ 抬高:无灯帧正确弃权↑ 的同时,**暗淡/模糊的真绿帧也被弃 → 漏绿破80**。
- **要求**:τ 选取把 **漏绿 ≤ 80 设为硬约束**(不是事后附注);gate 里**漏绿 > 80 直接判不过**。本项目误绿(诬告无辜)优先,但漏绿翻倍=漏检违章同样净回退,两头都不许。
