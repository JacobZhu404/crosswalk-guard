## 1. 方法(只读, 零生产码改动)

- **数据源**:生产链一次全 11 跑(`cli.run`,detector=v2、occ_denom=box、preset=balanced —— 与 cc gate `eval_violations.py --detector v2 --occ-denom box` 同源、同配置)。
- **探针**:`BatchViolationEngine._dedup` 入参 spy(拿**合并前**逐 track 原始事件 → 拆开时的潜在 episode 及其状态)+ `PlateConsensus.update` spy(逐 track 车牌读取全集,重放同款投票)。运行后还原,零改动。
- **A/B 分类锚**:每 episode 代表 track(max_overlap)为"违章车";每 member 与其做**同帧框对框** IoU + 质心距(最近邻配对 |Δt|≤0.5s@8fps)。
  - A=同车重编号: median_iou ≥ iou_thr **或** median_cd ≤ cd_thr;
  - B=异车误并: median_iou < iou_thr **且** median_cd > cd_thr;
  - U=无同帧可判(n_shared=0;附全局质心距灯)。默认 0.3/150。
- **B 语义判定(§3.2)** — 只对自身**confirmed** 事件者判(仅它们拆开才产生新 confirmed episode);
  - `gt_car` = 最高票牌 ∈ GT 窗牌表;
  - `bystander` = GT 窗有牌表 且 可读牌在其中 ⇒ 铁证非 GT 车;
  - `gt_unknown` = 读不到牌 或 GT 窗无牌(11 的 '?') ⇒ 盲盒, 球回;
  - `oow` = 自身事件与所有 GT 窗重叠 <0.5s。
- **GT 边界**:GT 仅 oracle;`datasets/gt/tracking/*.json` 的 frame.box 全 None → 权威 attribution_union 不可用 → 盲盒不硬凑(cc §4 护栏)。
- **护栏 落实**:set 判定只在高覆盖(episode 对 GT 覆盖≥0.7)上作结论(本批 8 个 confirmed 覆盖 0.90-1.00, 全符合);未用 gap 正负。

## 8. 修法草案与评测语义裁定(球回项)

**目标**:在**不新增 confirmed episode**的前提下消除脏袋(硬条件① 打开的禁区边界,§2.2)。

- **方案 α(身份约束进 _dedup,零拆)**:吸收判定 = 时序相邻 + **空间身份一致**(代表车框 IoU/质心链)。效果:窗外成员(tid17/20/22/64 等)不再被链式吸进 → 窗口向真窗收敛(§5 表);对 cc 铁证 07 track20:0.122<0.3 永不入袋 ✔。**副作用**:07/03/09 的 GT 车碎片(京Q5D2N8/京ABV3428/京AC63971,空间相离)—— 它们不会与代表车身份一致 → 不被并入 → **各自成新 episode?!** → 又 →fp 破 P!! ⇒ α 不能裸上, 必须与"多车窗保护"合设 (β)。
- **方案 β(多车窗合并保持:开合判定)**:身份不一致但**同窗共停**(同绿灯段不同车位)的成员→特殊合并(不新增窗);身份不一致且**时域不重叠**(仅 gap 或前后搭)的成员(窗外类)→照 α 挡出。**难点**:生产无 GT, "同窗共停"与"搭车"的区分依赖 —— 站姿+同窗格, 这是身份证据盲区(member 读牌 97 盲盒正落在此)。
- **方案 φ(只修窗口,不拆)**:合并语义从"吸收成员"改为"只为窗时间跨度取并,成员归属另表"(即把 b2 的 `member_tracks` 收窄提升为合并判定的第一性原则)。窗口自身不受影响的真实兜底 —— 与 b2 效果叠加,但**不再产生新 episode** —— 由 §2.2 唯一指向。φ 的实操形状 = α 去掉"多车并"分支。
- **评测语义裁定(交 Jacob/Junior)**:Q1 是否允许"一 GT 窗多 pred"(窗级 → 车内级)? Q2 "fragment" 是否移出 fp 单列指标? Q3 现 5 条硬条件(尤其①)是否按窗级还是 pred 级重述? —— 本诊断提供的事实:当前语义下"拆=必破P"。
