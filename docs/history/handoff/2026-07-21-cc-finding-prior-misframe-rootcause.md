# CC 发现+裁定:prior 系统性偏框(生产+挖矿共用)= 灯态判别器修不好的根因;停 Step2 sweep,转 prior 重定位

> 出自 cc(arbiter)。Jacob 用画框工具产出**信号灯位置硬真值**(02 对照验证方法可信),
> 客观坐实 `configs/light_priors.json` 对多数视频**完全偏框**。这是本立项以来最关键的一根线头。

## 0. 结论抬头
- **硬真值确认**:05/06/09 的 prior 与真灯 **IoU=0**(完全错位),09 偏 0.43(画面另一侧);03 采样帧内找不到灯;仅对照 02 正确。
- **影响面**:`light_priors.json` **生产 `observe()`/`detect()` 与挖矿共用**(traffic_light.py:118,120)。**训练 crop 直采 prior ROI → 多数视频是背景**(确认);生产 observe() YOLO 优先、prior 作选择器/回退 → 生产是否也被误导须单独查(§3)。
- **裁定**:**停 Step2 信号过滤 sweep**(过滤错框 crop = 洗背景,数字无意义);**转 prior 重定位**:全 11 视频画框真值 → 重建 `light_priors.json` + 收紧框 → 重挖 clean crop → 再训。
- **必查矛盾**:git log 称这些 prior 经"画廊标注驱动"调优提升了灯态准确率,与真值 IoU=0 矛盾 → 灯态 eval 指标恐对错位 prior 也放行(metric validity)。查清前**不信任何 prior 调优史**。

**两个独立病**:
1. **定位错**(05/06/09):prior 中心指错地方(IoU=0)。真灯位置其实集中在 x≈0.6/y≈0.3,已知 → 重定心可救。
2. **框过大**(全体含 02):真灯宽仅 ~0.02–0.03,prior 框 0.083 ≈ **3 倍** → 即便框对(02)crop 也被背景淹没,坐实"39% 无信号 / median 1.6%"。
3. 第三种:03 采样帧内无灯(待补帧,判"定位错"还是"灯不可见方法边界")。

## 2. 为什么这解释了"灯态判别器怎么修都修不好"
- classifier_retrain 正样本(walk/stand)= prior ROI 直采裁图。prior 偏框 → 正样本大多是树/楼/车窗背景被标成 walk/stand。
- 之前抽检验证过:04/05 的删+留 crop 都不是灯(留下的只是"带绿斑背景")。信号占比过滤只是把纯背景换成带绿斑背景 → **Step2 sweep 跑了也是拿背景训练**,故停跑。
- 关3=0(04 walk→stand)、关1/关4 负例拒识差,都与"判别器从没见过真灯正样本"自洽。

## 3. 必查项(下一步并行)
1. **生产影响面**:观测 observe() 优先级(YOLO→prior→亮斑)。prior 偏框在 YOLO 命中时是否会"选到离错位 prior 最近的错框"(traffic_light.py:149 "有prior时选离prior最近的框")→ 可能主动误导,非仅回退。须在真视频上量化生产灯态是否也受损,还是 YOLO 兜住。
2. **灯态 eval metric validity**(measurements-disagree):git log(472d9a1/8b863f1/8e6f6d2/c26b3f3 等)称修 prior 提升灯态准确率,与真值 IoU=0 矛盾。查那套准确率到底测什么、为何错位 prior 也能涨 → 若指标能被错位 prior 蒙过,则相关调优史与 E2E 灯态数字都要重估([[eval-methodology-gap-overfit]])。

## 4. 裁定与下一步
- **停**:Step2 信号过滤 sweep 不跑;`labels.filtered.csv` 保留但不作训练输入(建立在偏框数据上)。
- **转 prior 重定位**(按序,先计划后动):
  1. **全 11 视频画框真值**(Jacob 之前 defer 的"全量定位框"选项;最小验证已完成且结论确凿,现升级为全量)。每视频真灯框(固定机位,1 框 + 抽 2–3 帧确认不动)。
  2. 重建 `configs/light_priors.json`:中心=真灯中心,**roi_px 收紧**到贴合真灯(现 160/220 过大)。改动须同时验生产 observe() 不回退。
  3. 按新 prior **重挖** clean crop → 走新目录 `classifier_retrain_v2/`(红线:重挖仅放行后)→ **重跑画廊抽检确认框住灯**。
  4. 在干净数据上重训 → 才谈 gate(≥5 seed mean±std+min)。
- **并行**:§3 两项(生产影响面 + eval metric validity)。
- 03/其余未标视频:补帧确认"定位错(可救)"vs"灯不可见(方法边界)"。
