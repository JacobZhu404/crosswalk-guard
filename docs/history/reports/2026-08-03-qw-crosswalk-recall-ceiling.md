# 斑马线检测召回天花板诊断(qw, 只读)

> 量 v11(全宽横带)和 v2(透视梯形)相对 GT poly 的差距, 拆成召回 vs 几何过宽。

> v11 = `CrosswalkDetector.detect(frame)` 不传 vehicle_boxes(本征掩膜质量, 与 eval_crosswalk_mask.py:52 一致)。

> v2 = `CrosswalkDetectorV2.detect(frame)`, 每帧独立实例(量单帧质量, 不走时序聚合)。

> GT = `datasets/gt/crosswalk/`, poly 像素坐标, `poly_to_mask` 栅格化。

> recall = |pred∩GT|/|GT|, precision = |pred∩GT|/|pred|, 单次跑无 seed。


## 三问裁断

**Q1 IoU 天花板**: v11 均值 IoU=0.011, 范围 [0.000, 0.117]; IoU<0.5 的视频: ['违章02', '违章03', '违章04', '违章05', '违章06', '违章07', '违章08', '违章09', '违章11']

**Q2 召回 vs 几何过宽**: v11 recall 均值=0.012, precision 均值=0.093 → **召回不足为主**(35/35 帧 recall<0.5)。斑马线条纹没检到 → 需提检测灵敏度/降阈值, 非形状问题。

**Q3 v11 vs v2**: v2 IoU 均值=0.249 vs v11=0.011, v2 优 35/35 帧 → 梯形方向可行, 值得立项完善。


## denom=mask 稀释效应(分析讨论)

v11 全宽横带 → mask_area 巨大 → `compute_overlap_ratio(denom='mask')` 的 `inside/mask_area` 被稀释。历史实验 denom=box(F1=0.941) > denom=mask(F1=0.875) 与此一致: 全宽带不只压 IoU, 还压 denom=mask 下的占道比。修形状(约束带宽/上梯形)可同时改善 IoU 和 denom=mask 占比。

## 方法学

- 复用 `eval_crosswalk_mask.py` 的骨架, 加 recall/precision 分解。

- v11/v2 每帧独立实例(量单帧掩膜质量, v2 不走时序聚合)。

- `poly_to_mask(poly, H, W)` 用实际 `frame.shape`, 不硬编码分辨率。

- v11 不传 vehicle_boxes(纯检测天花板, 与 eval_crosswalk_mask.py:52 一致)。

- 经典 CV 确定性, 单次跑无 seed。

- 逐帧 CSV: `data/output/qw/crosswalk_recall_ceiling_per_frame.csv`
