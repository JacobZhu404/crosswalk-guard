## 2. P2 — 事件车牌回填安全约束(优先级 0, 先做)

**问题**: `_episode_plate`(cli.py:182)从 track_id+member_tracks(脏袋)取 weight 最高牌, **无时间/空间约束** → 违章02 回填过路车牌京A14672(开错罚单)。

**改法**(`cli.py _episode_plate` + 事件车牌回填逻辑):
1. **时间约束**: 候选牌读取帧 ts 必须 ∈ [ev.start_ts - ε, ev.end_ts + ε](ε=1s); 事件窗口外的读取(tid 131 的京LNE560 107s+)不参与
2. **空间约束(同一性判定)**: 候选牌的 plate 框与**事件代表 track 车辆框**空间关联——plate 框中心落在代表 track 该时段的车辆框内(或 IoU>0), 或与代表 track 质心距离 < 阈值; 不满足的候选(tid 68 过路车 x=87 vs 白车 x=615)剔除
3. **宁缺毋滥**: 过滤后无候选 → 返回空串(而非窗口内别车牌); 事件 CSV 车牌为空 = "待人工补牌", 不可自动填错
4. 数据源: 回填需逐帧 plate 读取(ts, text, box, 关联 tid)——当前 `plate_consensus` 已按 tid 累积(含 timestamps), 但**缺 box 与帧级 ts 到 tid 的关联**, 需在 `n_consensus`(dag.py:96-110)把 plate 框随 update 一起记录(纯加性: consensus 记录结构扩展, 不影响投票)

**验收(P2 独立)**: 11 视频事件车牌回填 vs GT——违章02 不再回填京A14672(空牌), 其余 6 命中不回退, 负例零新牌。**P2 不提升命中率, 消除开错罚单**(0 误罚)。

## 3. P1 — per-event 车辆同一性判定 + 多车多牌(优先级 1)

**问题**: 单事件单牌(语义) + member_tracks 脏袋(数据) → 07/08/09 多车只回填 1 个, 且脏袋里随时可能冒出过路车牌。

**改法**(在 P2 之上):
1. **member_tracks 归组(同一性判定)**: 按"车辆框空间连续 + 时间重叠"把 member_tracks 聚成 k 个**车组**(每组 = 同一辆车的 track 片段合并; 过路车 track 若与代表 track 空间无重叠则自成组或剔除)
2. **每组取 1 牌**(P2 约束下该组 consensus best); 事件输出"per-vehicle 车牌列表"(结构扩展: ev["plates"]=[{track_group, plate, conf, ts}] + 兼容旧 ev["plate"]=代表组主牌)
3. 过路车组(与代表 track 空间不连续)不产生车牌
4. 归组算法: 用现有 track 框轨迹(engine 已累积 `_track_samples`)做时空聚类——**不改 tracker 本体**(b2 过合并是 tracker 上游问题, 超本 scope, 记录为独立项)

**验收(P1)**: 07(京ACG0878 回填)/08(京ACW6553)/09(京NNM526) 各 +1 → 事件车牌命中率 6/12 → **9/12 = 75%**(cc 预估吻合); 违章02 保持空牌不误罚。

## 4. P3 — 事件窗口内低曝光车牌放大重试(优先级 2)

**问题**: 京LNE560(事件窗口内白车 0 读取)/京ADH9206(全视频 1 帧 ED=2)——低曝光车牌 HyperLPR3 全图检测漏。

**改法**(plate 层, `dag.py n_plate` 或 cli 回填前重试):
1. 对事件代表 track(及 P1 车组), 取事件窗口内车辆框, **车框下缘 ROI 放大 2× 裁剪**重跑 HyperLPR3(HIGH); 每次 detect 已有 vb, 补一次 ROI 重试(纯加性, 失败不改变原结果)
2. 只对"原全图检测无牌/低 conf"的 track 触发, 避免每帧双跑的开销

**验收(P3)**: 违章02 京LNE560 窗口内重试读到 → 事件回填京LNE560(命中 10/12≈83%); 京ADH9206 若窗口内放大仍读不出 → 如实记录(可能物理不可读), 归 d 桶终态。
