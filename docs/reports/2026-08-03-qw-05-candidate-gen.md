> 天花板诊断把候选生成瓶颈收窄到 违章05(天花板仅 10.0%)。逐 30 gov 帧解剖根因。

> 核心口径疑点: 05 天花板 10% 是生产真烂, 还是 eval 候选口径没跑 prior 直采路径的伪影?

> 候选构建口径与 `eval_selection_quality.py:eval_video:99-104` 逐行一致; prior 直采调 `traffic_light.py:597 _sample_prior_color`。

> prior = [0.7, 0.15, 160] (cx, cy, roi_px)


## 裁断

**C prior 偏框: >50% 帧 prior 中心不在 gov 附近, 需重定位 05 的 prior。**


## 聚合 (30 gov 帧)

- prior = [0.7, 0.15, 160]
- YOLO IoU≥0.3: 2/30 = 6.7%
- HSV(_candidates) IoU≥0.3: 1/30 = 3.3%
- **prior直采命中(非None): 30/30 = 100.0%**
- prior直采颜色匹配: 15/30 = 50.0%
- 小灯(area<30px): 0/30 = 0.0%
- 低饱和(S<130): 18/30 = 60.0%
- gov中心在prior ROI内: 0/30 = 0.0%
- 失败归因分布: {'C': 30}

## gov 灯实际位置 vs prior

- prior 中心: cx=0.700, cy=0.150
- gov cx 范围: 0.252 ~ 0.667 (均值 0.580)
- gov cy 范围: 0.295 ~ 0.402 (均值 0.336)
- **Y 方向偏差最严重**: prior Y=0.150 vs 实际 Y~0.336, 差 0.186 (约 19%)
- prior 直采 100% 返回 'green' 是在错误位置采到别的绿色物体(50% 颜色匹配 = 随机概率), 不是真命中 gov 灯。


## 失败归因定义

- **A**: 小灯被面积过滤 (gov area < 30px, _candidates min_area_px 截掉)
- **B**: 暗灯被 HSV 阈值过滤 (S < 130 或 prior 直采也捞不回)
- **C**: prior 偏框 (gov 中心不在 prior ROI 内)
- **D**: 口径伪影 (prior 直采能命中, eval 候选口径没跑 prior 路径)

## 方法学

- 候选构建复用 `gd._read_frames_at`/`gd._lazy_yolo`/`gd._cfg_tl`/`det._candidates`/`build_candidates`/`iou`。

- prior 直采: `det._last_frame = frame` + `det.signal_prior = (cx, cy)` + `det._sample_prior_color()`。

- _candidates 阈值: sat_min=130, value_floor=60, min_area_px=30, color_s_min=22。

- _sample_prior_color 阈值: S≥60, V≥40, 无面积过滤, min_frac=0.2%, 自适应 2x 扩展。

- 只读诊断, 不训练、不改生产代码、不碰 s1/_A 缓存。

- 逐帧明细 CSV: `data/output/qw/05_candidate_gen_per_frame.csv` (供 cc bit-for-bit 复核)。
