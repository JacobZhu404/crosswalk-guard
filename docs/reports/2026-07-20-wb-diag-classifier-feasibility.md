## 0. 执行方式

- **(A) 域内 sanity**: 在 `datasets/ped_signal/` 2658 张已标 crop (walk/stand/off, **仅 02/03/04**) 上跑冻结 `ped_signal.pt`, 出混淆矩阵。
- **(B) 端到端产绿区判别**: 用 `TrafficLightDetector.observe()` (`method="color"`, 复现 0.889 报告管线) 复现各视频"引擎判绿"的帧; 因 **11 视频均有 prior**, observe() 实际走 prior ROI (Exit B), 故裁 **prior ROI 框**(=引擎判定区, 与训练分布同尺度) 送判别器分类。
- **判定口径**: 判别器 `off`=拒(非信号), `walk`=绿(收), `stand`=红(收)。负例视频(01/10)的引擎绿=假绿; 正例视频的引擎绿=真绿。

## 2. (b) 泛化 — **失败**

训练集仅 02/03/04 (3 视频)。未见视频 (05–11) 上:

- **06: 153 真绿 → 152 (99%) 拒**; **07: 164 → 161 (98%) 拒**; 09: 370 → 80 (22%); 11: 52 → 21 (40%).
- 正例合计 **41% 误拒真绿**。
- **07 暗绿 (简报硬要求"必保") 被 98% 拒** → 判别器认不出 07 信号; **04 短绿 57% 拒** → 试金石未过。
- 机制: 判别器只在 02/03/04 外观上学到信号; 06/07/09 不同相机/光照 → 真绿被判 off。walk 少数类偏置加剧。07 低置信仅 2/164 → 是**自信地错拒**(过拟合特征)。
- 全部 11 视频均有 prior, observe() 走 prior ROI, 故以上裁剪=引擎实际判定区, **非裁剪偏差**。

→ 严重过拟合, 当前 pt 不可用于未见视频。

## 3. (c) 接线缺口 + 插入点 + 成本

- **确认**: 判别器仅在 `detect()` 当 `method=="ped_classifier"` 时调用 (`_detect_ped`, `traffic_light.py:245-289`); 0.889 报告管线用默认 `method="color"` → **判别器当前完全未接入违章管线, 是死代码**。
- observe() 三产绿出口均**不调**判别器:
  - **Exit A** (`:189-194`): YOLO 框 `_sample_box` 绿
  - **Exit B** (`:197-203`): prior ROI `_sample_prior_color` 绿 ← 11 视频实际走这条
  - **Exit C** (`:210-230`): candidates 面积求和绿
- **插入点**: 在每个出口 `return green` 前, 裁该绿区 ROI 送判别器; 若 `classify=="off"` → 改判 `off`/`unknown` (恢复 D1 安全网)。
- **成本**: 每产绿帧 +1 次 48×48 tiny-CNN 前向 (CPU 可忽略, ~0.1ms), 接口零新增依赖 (torch 已在运行时)。

## 4. (d) 483 帧误绿出口定位

来源 (plan v7 §28): **环境绿~200 / unknown 被迫选绿 152 / 反射~131**。

- 环境绿 + 反射 → 主要 **Exit B** (prior ROI 采到非信号绿) / **Exit C** (全局亮斑求和)。
- unknown 被迫选绿 → `_state_from_global` 时序融合强行给绿 (observe 的 obs 是原料)。
- 判别器本可治"环境绿"(把非信号绿判 off), 但 §2 证明它**同时误拒真绿** → 净回退。

## 5. (e) 可行性三选一

- **(a) 治本可行 (接线+重训)**: **否 (当前 pt)**。把当前 pt 接成门控 → 06/07 真绿 99%/98% 被拒 → 灾难性回退, 直接违反**钢锭②"净回退不上"**与安全侧"误绿比漏短绿严重"。
- **(b) 不可行 (需更好数据/模型)**: 当前 pt 不可用。根因 = **过拟合** (仅 02/03/04) + **walk 少数类偏置** + **零负样本** (训练集无任何背心/植物/反射 impostor, 全是 prior ROI 内真信号)。治本方向 (学习式判别器) 本身成立, 但须**重训**: 数据须覆盖**全部 11 视频信号外观** + **显式 impostor 负样本** (背心/植物/反射/车灯) + **walk/stand/off 平衡**。此步依赖 Jacob §7 拍板 (是否标新 crop)。
- **(c) 回退 (位置+时序稳定门控, 非颜色)**: Phase 1 已证净回退 0.889→0.842, 未合入 main。**不可行**。

### 建议
当前 pt **不要**接门控 (会回退 06/07/04)。走 **(b)**: 先建重训数据集 (11 视频信号 crop + impostor 负样本, 类平衡), 重训后重做本诊断验证泛化。04 按 Plan v7 既定"接受继续漏"。此步依赖 Jacob §7 标注决策。

## 6. 给 cc 的根因判定

根因不是"判别器能不能认绿", 而是 **现有 pt 是个 3 视频过拟合的弱分类器** (域内 80% acc、零负样本、walk 偏置), 接门控会**同时杀真绿与漏假绿 → 净回退**。治本方向对, 但当前资产不够, 需重训数据投资。

- **(ii)** 接受现状 (04 漏 + 01 误绿保留), 先转其它杠杆 (如 B2 跟踪已收官, 或别的模块)。
